# Sonssies 단계별 화면 구조 계획 (모바일 우선)

> 상태: 계획 확정, 실행 전 (2026-10-30)
> 실행은 아래 "진행 순서"대로 한 단계씩. 각 단계 끝나면 아티팩트에 반영 → 사용자가 "깃허브에 반영해줘" 하면 사이트에 올림.

## 1. 전체 흐름

**처음 방문**
인트로(홈 화면 앱만) → 알 깨기 → 시작 고르기(프리셋 3 / 랜덤) → 꾸미기 8단계 → 이름 짓기·저장 → 메인

**다시 방문**
인트로(홈 화면 앱만) → 메인

**메인**
도깨비 + 말풍선 → [꾸미기] [카드 만들기] [배경화면 만들기]

## 2. 화면별 내용

### 인트로
- 지금 만든 것 그대로. 홈 화면 앱으로 열 때만. 사파리로 들어올 때는 보여주지 않음.

### 알 깨기 (처음 한 번만)
- 도깨비알 하나. 처음에 "톡톡 두드려 봐!" 안내.
- 터치할 때마다 **터치한 자리**에서 금이 감. 두드릴수록 알이 크게 흔들림.
- 12번째 터치에 빛이 나며 알이 열리고 **깨두가 튀어나옴** → "꾸며볼까?" → 시작 고르기.
- 안드로이드는 터치마다 짧은 진동(아이폰 웹은 진동 불가).
- 뒤로가기로 다시 돌아오지 않음.

### 시작 고르기
- 프리셋 3개(깨두·꼬마·꼼디) + 랜덤. 랜덤은 포즈 없이 기본 포즈.
- 이름 칸 없음(이름은 마지막 단계에서).

### 꾸미기 8단계
위에 진행 막대(1/8 …). 모든 단계에 [이전] [다음] + **[이대로 완성]**(바로 이름 짓기로).

| 단계 | 내용 |
|---|---|
| 1. 색·질감 | 피부색, 매트/글로시 |
| 2. 머리·뿔 | 머리 너비·높이·두께·모양 / 뿔 켜기·길이·두께·간격 |
| 3. 귀 | 귀 관련 슬라이더 |
| 4. 눈·눈썹 | 눈 모양, 크기·간격·높이 / 눈썹 길이·각도·두께·높이 |
| 5. 코·입·볼 | 코 / 입 모양·관련 슬라이더 / 볼살, 볼터치 켜기·색 |
| 6. 몸 | 길이·너비·두께·허리 |
| 7. 팔·다리 | 팔 길이·두께 / 다리 길이·두께 |
| 8. 꼬리 | 꼬리 켜기·크기·너비 등 |

- 화면 위쪽은 3D 도깨비(지금처럼 돌려보기·확대), 아래쪽은 그 단계 슬라이더만.
- 지금 화면의 아코디언 구조를 단계 페이지로 나누는 방식.

### 이름 짓기·저장
- 이름 직접 입력 + 랜덤 주사위. 규칙은 지금과 같음(띄어쓰기 없음, 한글 8자 / 영문 12자).
- 이름은 **이름표 스티커 위에** 바로 보임. 말풍선 없음.
- 이름표 색은 따로 고르지 않고 **도깨비 피부색과 비슷한 색으로 자동**(지금의 "기본" 이름표 색 규칙).
- **배경색**을 여기서 바꿀 수 있음. 고른 배경색은 메인 화면 배경에도 씀.
- [저장하기] = 도깨비를 기기에 저장하고 메인으로(이미지 파일 아님).

### 메인
- 내 도깨비 + 말풍선. 들어올 때마다 다른 말.
  - 시간대별: 아침 "잘 잤어?", 점심 "밥 먹었어?", 밤 "졸려…" + 공통 "안녕!", "반가워!" 등.
  - 도깨비를 톡 누르면 통통 튀고 말이 바뀜.
- 버튼: [꾸미기](8단계로 다시 들어감) [카드 만들기] [배경화면 만들기].
- 도깨비는 한 마리만.

### 카드 만들기
- 지금의 완성 화면(1080×1920 카드)을 이 페이지로 옮김: 말풍선, 이름표 켜기/끄기, 배경색, 이미지로 저장.
- **포즈 고르기**를 여기에 추가.

### 배경화면 만들기
- 페이지만. "서비스 제작 중…" 안내와 뒤로가기.

## 3. 공통 규칙
- **뒤로가기:** 화면 왼쪽 위 뒤로 버튼 + 휴대폰 뒤로가기(스와이프·뒤로 버튼)가 같게 동작. 꾸미기 단계에서는 이전 단계로. 알 깨기로는 돌아가지 않음.
- **저장:** 도깨비·이름·배경색·진행 단계를 기기(브라우저)에 저장. 꾸미다 앱을 닫아도 다시 열면 이어서.
- **주의(아이폰):** 사파리와 홈 화면 앱은 저장 공간이 따로. → 모바일 사파리로 처음 오면 "홈 화면에 추가하면 도깨비를 계속 키울 수 있어요" 안내를 먼저 보여주고, [브라우저에서 계속하기]도 둠. 나중에 필요하면 도깨비 옮기기(코드/링크) 또는 로그인 추가.
- **PC:** 같은 모바일 화면을 가운데에 휴대폰 폭으로.

## 4. 진행 순서
1. 화면 이동 구조(뒤로가기 포함), 기기 저장, 메인 화면
2. 시작 고르기 + 꾸미기 8단계
3. 이름 짓기·저장(이름표 자동 색, 배경색)
4. 알 깨기 연출
5. 지금 완성 화면 → 카드 만들기 페이지(+포즈)
6. 배경화면 만들기 페이지("서비스 제작 중…")

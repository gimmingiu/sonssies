# 나의 반려 도깨비 만들기

나만의 반려 도깨비를 꾸미고 1080×1920 이미지로 저장하는 웹페이지예요.

## 파일
| 파일 | 역할 |
|---|---|
| index.html | 페이지 전체 (3D 도깨비, 꾸미기, 완성 화면, 이미지 저장) |
| manifest.webmanifest | 휴대폰 "홈 화면에 추가" 시 앱 이름·아이콘 |
| sw.js | 한 번 열면 오프라인에서도 열리게 저장 |
| icon-*.png, apple-touch-icon.png | 앱 아이콘 |
| og.png | 링크 공유 시 미리보기 이미지 |

## GitHub Pages로 올리기
1. github.com → 오른쪽 위 `+` → **New repository** → 이름(예: `kkaedu`), **Public** → Create repository
2. 만들어진 저장소 화면에서 **uploading an existing file** → 이 폴더의 파일을 모두 끌어다 놓기 → **Commit changes**
3. 저장소 **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main** / **(root)** → Save
4. 1~2분 뒤 `https://<깃허브아이디>.github.io/kkaedu/` 로 접속

## 고칠 때
- 바뀐 파일만 다시 업로드(같은 이름으로 덮어쓰기)하면 1~2분 뒤 반영돼요.
- 휴대폰에 예전 화면이 남아 있으면 페이지를 한 번 새로고침하면 새 버전으로 바뀌어요.
